GPIO 풀업·풀다운 정리

풀업과 풀다운은 핀을 약하게 High나 Low 쪽으로 당겨서, 아무도 구동하지 않을 때의 값을 정해 주는 저항입니다.

저항과 전류, High/Low 판정 기준은 원리를 보기 위한 근사치입니다. 실제 값은 데이터시트를 따릅니다.

왜 필요한가

떠 있는 핀

입력 핀은 아무것도 연결되지 않으면 전압이 정해지지 않아, 노이즈에 따라 0과 1이 제멋대로 읽힙니다.

풀업

핀과 VDD 사이의 약한 저항입니다. 아무도 구동하지 않으면 핀은 High입니다.

풀다운

핀과 GND 사이의 약한 저항입니다. 아무도 구동하지 않으면 핀은 Low입니다.

약하다는 뜻

저항이 커서, 스위치나 MOSFET이 반대쪽으로 구동하면 그쪽이 이깁니다.

버튼 연결에 맞는 저항

버튼 연결필요한 저항안 누름누름
핀 ↔ VDD풀다운01
핀 ↔ GND풀업10

평소 상태는 버튼이 연결되지 않은 쪽 전원으로 맞춥니다. 보드에 외부 저항이 이미 있으면 내부 저항은 필요 없습니다.

내부 풀업과 외부 풀업

구분저항 크기High로 올라가는 속도쓰는 곳
내부약 40 kΩ느림버튼, 간단한 테스트
외부예: 4.7 kΩ더 빠름I2C처럼 빠른 신호

저항을 너무 작게 하면 Low일 때 흐르는 전류가 커지므로, 무조건 작게 하지는 않습니다.

헷갈릴 때 확인할 점

  • Push Pull은 칩이 High와 Low를 직접 구동하므로 풀 저항이 필요 없습니다.
  • Open Drain은 Low만 직접 만듭니다. High는 풀업 저항이 만듭니다.
  • 풀다운은 사실상 입력 핀용입니다. Open Drain에 달면 High를 만들 수 없습니다.
  • 상대가 Push Pull 출력이면 항상 값을 내보내므로, 입력 쪽에 풀 저항이 없어도 됩니다.
  • Push Pull로 High를 내는 핀을 다른 장치가 Low로 당기면 단락입니다. 여러 장치가 한 선을 쓸 때 Open Drain을 쓰는 이유입니다.
