# step_motor_KH42JM2_901

DRV8825로 KH42JM2-901 스텝모터 **하나**를 돌려 보는 시험 프로젝트이다.
TIM1 PWM으로 STEP 펄스를 만들고, 앞뒤로 가속 → 유지 → 감속을 반복한다.
2026-11-18에 실제 하드웨어에서 회전하는 것을 확인했다.

## 동작

```
while(1)
 ├─ DIR 설정 (멈춘 상태에서 바꾸기)
 ├─ step_ramp(100 → 600 Hz, 0.5초)   가속
 ├─ 600 Hz로 2초 유지
 ├─ step_ramp(600 → 100 Hz, 0.5초)   감속
 ├─ 정지 1초
 └─ 방향 반대로
```

- 타이머 클럭 170 MHz / (PSC 169 + 1) = 1 MHz tick
- STEP 주파수 = 1 MHz / (ARR + 1), duty 50%
- DRV8825 M0~M2를 연결하지 않아 Full step (200 스텝/회전)

## 핀

| 신호 | 핀 | 설정 |
|---|---|---|
| STEP | PA8 | TIM1_CH1, PWM |
| DIR | PB5 | GPIO Output |

DRV8825의 RST와 SLP는 서로 묶어서 3.3V로 올렸다.

## 겪은 문제

- **STM32와 DRV8825 사이에 GND를 연결하지 않았을 때**: 한 방향으로는 돌다가, 반대 방향에서 웅웅거리며 멈췄다. GND를 연결하니 정상으로 돌았다. 모터가 이상하게 움직이면 공통 GND부터 확인한다.

이 시험 결과를 바탕으로 [Step_Line_Tracer](../Step_Line_Tracer)에서 모터 2개를 구동한다(핀 배치는 다름).
